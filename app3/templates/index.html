Collaborative Filtering

Tourism Recommendation

Pick a user ID and the model will compare that user with similar users to rank attractions they are most likely to enjoy.

How it works

Select a user ID, choose how many recommendations you want, and optionally filter by city. The app then predicts the best matches from the expanded attraction list.

Note: The recommendations are based on user similarity, so changing the user ID can produce a very different result set.
